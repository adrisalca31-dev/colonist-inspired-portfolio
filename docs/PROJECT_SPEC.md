# Project Specification

## 1. Project Overview

### Project Name

**Adrian's Interactive Developer Portfolio**

### Description

This project is an interactive developer portfolio designed and developed specifically as a personal side project and as an experimental project inspired by Colonist.

The portfolio will combine a professional presentation with a highly interactive user experience inspired by the visual language, interface patterns, and game-like feel of Colonist. The goal is to create a portfolio that feels like a real product rather than a conventional portfolio template.

The project will be developed primarily through AI-assisted software development. AI will be responsible for generating and modifying a significant portion of the code, while the human developer will define requirements, provide specifications, guide the development process, review implementations, test functionality, make technical decisions, and validate the final result.

The project will use a modern full-stack architecture and, when appropriate, technologies that are relevant to Colonist's current development environment.

### Primary Objective

The primary objective is to create a portfolio that can demonstrate the ability to use AI effectively to build, iterate, test, and ship a real software product.

The project should demonstrate:

* Strong attention to user experience and visual detail.
* Ability to turn ideas into functional features.
* AI-assisted software development.
* Frontend and backend development.
* API development and integration.
* Database design and data management.
* Testing and debugging.
* Version control and collaborative development practices.
* Technical decision-making and architectural thinking.
* Willingness to experiment and learn new technologies.

The portfolio will be particularly oriented toward a potential future application to Colonist, with the goal of creating something that demonstrates genuine interest in their product, development philosophy, and technology environment.

### Secondary Objective

The portfolio should also be impressive and enjoyable to explore for developers and recruiters outside of Colonist.

It should communicate that the project was intentionally designed and engineered rather than generated from a generic portfolio template.

### What This Project Is Not

This project is **not** intended to be:

* A direct copy or clone of Colonist.
* A generic portfolio template.
* A static collection of links to GitHub repositories.
* A project created only to demonstrate the number of technologies used.
* An attempt to reproduce Colonist's complete game or product.
* A replacement for the developer's professional GitHub portfolio.
* A project where AI-generated code is accepted without review or testing.

The project will take inspiration from Colonist while maintaining its own identity, content, architecture, and purpose.
