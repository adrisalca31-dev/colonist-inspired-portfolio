# Adrian's Interactive Developer Portfolio

A game-inspired, interactive developer portfolio built to showcase product thinking, full-stack development, and AI-assisted engineering. The experience takes visual inspiration from board-game interfaces while remaining focused on a professional portfolio presentation.

## Tech stack

- React 19
- TypeScript
- Vite
- CSS
- Oxlint

## Run locally

From this directory:

```bash
npm install
npm run dev
```

The development server will print the local URL. Additional commands:

```bash
npm run lint
npm run build
npm run preview
```
